## Open-Source Projects

### [`dotai-cli`](https://github.com/nbslabs/dotai-cli) - Flagship Project

> One `.ai/` folder to rule all AI coding tool configurations.

[![npm version](https://img.shields.io/npm/v/@nbslabs/dotai.svg)](https://www.npmjs.com/package/@nbslabs/dotai)
[![npm downloads](https://img.shields.io/npm/dm/@nbslabs/dotai.svg)](https://www.npmjs.com/package/@nbslabs/dotai)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/nbslabs/dotai-cli/blob/main/LICENSE)

**dotai** solves a painful problem in AI-augmented development: every AI coding assistant (Claude Code, Gemini CLI, Cursor, Copilot, Windsurf, Antigravity, Codex) expects its configuration in a different file at a different path. dotai creates a single `.ai/` directory as your source of truth and symlinks everything to where each tool expects it. Edit one file, every tool stays in sync.

```bash
npm install -g @nbslabs/dotai
cd your-project
dotai init
```

| | |
|:--|:--|
| **Package** | [`@nbslabs/dotai`](https://www.npmjs.com/package/@nbslabs/dotai) |
| **Language** | TypeScript |
| **License** | MIT |
| **Homepage** | [dotai.nbslabs.dev](https://dotai.nbslabs.dev/) |

**Key Features:** Single `.ai/` config directory, symlink-based multi-tool sync, Resource Management CLI (MCP servers, skills, rules, slash commands), Spec-Driven Development (SDD) workflow, AI-driven Knowledge Base, built-in `/git-stage-commit` command.

### [`difflense`](https://github.com/nbslabs/difflense)

> A clean, secure, privacy-focused git diff viewer that processes everything client-side.

[![Stars](https://img.shields.io/github/stars/nbslabs/difflense?style=flat)](https://github.com/nbslabs/difflense/stargazers)
[![license](https://img.shields.io/badge/license-GPL--3.0-green.svg)](https://github.com/nbslabs/difflense/blob/main/LICENSE)

Upload a diff file or paste raw diff text to explore changes with a clean, structured view. Built for clarity, DiffLense helps developers review, analyze, and share code diffs more effectively - all without sending any data to a server.
